**If Slack, Cursor, and Google Docs had a baby.**

Team chat like Slack. An AI agent that actually builds the work like Cursor. A plan you
edit together, live, like Google Docs. Talk an idea through, shape the plan with your
team, then hand it to the agent — and watch the result render as it ships.

## The agent is a teammate, not a tool

The agent has a name and a face in the roster, gets @-mentioned, reacts, and picks up
work like anyone else — same presence, same avatar, no separate "bot" treatment.

## Open source & self-hostable

kordeon is fully open source. Run it on your own infrastructure and keep your data
in-house — nothing is locked behind our servers.

```sh
git clone https://github.com/ilbertt/kordeon.git
cd kordeon
bun install
```
